学习通视频学习助手

«更轻盈，也更清晰。让视频学习操作更方便。»

当前版本：v3.3.8

基于 Tampermonkey（油猴）的学习通网页端辅助脚本，提供视频播放控制、倍速设置、播放状态监测、章节切换及可自由调整的悬浮控制面板。

无需安装独立软件，安装油猴脚本后即可在支持的课程页面使用。

"📄 查看脚本源码" (https://github.com/wwww-start/xuexitong-shuake/blob/main/v3_optimized.user.js) · "🚀 安装脚本" (https://raw.githubusercontent.com/wwww-start/xuexitong-shuake/main/v3_optimized.user.js) · "💬 问题反馈" (https://github.com/wwww-start/xuexitong-shuake/issues)

✨ 功能介绍

🎨 液态玻璃悬浮面板

采用 macOS 风格液态玻璃设计，轻巧简洁。

- 自动适配系统浅色 / 深色模式
- 支持拖动面板，自由调整位置
- 支持拖动右下角，调整面板大小
- 支持收起 / 展开，减少页面遮挡
- 自动保存面板的位置、尺寸和展开状态

🎬 视频播放辅助

- 自动播放：进入支持的视频页面后尝试自动播放。
- 自动切换章节：检测到视频播放结束后，尝试进入下一学习小节。
- 倍速调节：支持 1×、1.25×、1.5×、1.75×、2×。
- 播放恢复：检测到意外暂停、卡住等情况时，尝试恢复播放。
- 跳转进度：可以手动请求跳转至当前视频最后一分钟。
- 后续自动跳转：开启后，对后续加载的视频尝试自动跳转至最后一分钟。
- 章节测验处理：遇到独立章节测验页面时，尝试进入下一学习步骤，不会自动答题。

«注意：部分课程会限制播放倍速、进度拖动或章节切换。脚本发出操作请求不代表平台一定接受。»

📊 实时状态显示

悬浮面板可显示：

- 当前视频名称
- 当前播放时间 / 视频总时长
- 实际播放倍速 / 设置倍速
- 当前运行状态
- 最近操作信息

无需打开开发者工具，也能直观了解脚本的工作状态。

📥 安装教程

第一步：安装 Tampermonkey（油猴）

首先确保浏览器已安装并启用 Tampermonkey 扩展。

推荐使用 Chrome、Edge 或 Firefox 等支持用户脚本管理器的桌面浏览器。

油猴官方网站：

https://www.tampermonkey.net/

根据浏览器类型安装对应扩展，并确认扩展已启用、具备运行用户脚本所需的权限。

第二步：安装学习通脚本

点击下方链接：

"👉 点击安装学习通视频学习助手" (https://raw.githubusercontent.com/wwww-start/xuexitong-shuake/main/v3_optimized.user.js)

如果浏览器正常识别用户脚本，将出现 Tampermonkey 安装页面。

点击安装即可完成。

如果点击后只显示代码，没有弹出安装界面：

1. 打开 Tampermonkey 管理面板。
2. 点击「添加新脚本」。
3. 删除编辑器中原有的模板代码。
4. 打开上面的脚本链接，复制全部源码。
5. 将源码粘贴到油猴编辑器中。
6. 保存脚本，并确认脚本处于启用状态。

第三步：打开学习通课程

1. 使用浏览器登录学习通。
2. 进入需要学习的课程。
3. 打开包含视频的具体课程学习页面。
4. 等待页面加载，必要时刷新一次。

正常情况下，页面右下角会出现 「学习助手 · 3.3.8」 悬浮面板。

脚本主要适配超星学习通网页端的 "studentstudy" 课程学习页面，不保证兼容全部新版页面、自定义学校平台或手机 App。

🎮 使用教程

1. 启用或关闭脚本

在悬浮面板中找到 「启用脚本」 开关。

- 开启：运行视频播放辅助和自动章节切换等功能。
- 关闭：停止脚本的自动播放、状态监测和自动切换操作，并尝试暂停当前视频。

默认情况下，首次安装后脚本处于启用状态。

2. 设置播放倍速

在 「播放倍速」 菜单中选择需要的播放速度。

倍速| 说明
1×| 正常速度
1.25×| 1.25 倍速
1.5×| 1.5 倍速，默认设置
1.75×| 1.75 倍速
2×| 2 倍速

选择后，脚本会尝试应用到当前播放器。

注意： 某些课程可能强制限制倍速。如果面板显示的实际倍速与设置倍速不同，请以实际播放状态为准。

3. 手动跳转视频进度

点击 「跳到最后 1 分钟」。

脚本会尝试将当前视频的播放位置调整到距离结束约一分钟处。

例如，一个 30 分钟的视频，会尝试跳转至 29:00 附近。

如果当前视频时长尚未加载，或课程限制进度拖动，操作可能不会生效，面板会显示相应提示。

4. 开启后续自动跳转

打开 「后续自动跳转」 开关。

开启后，脚本会在后续视频加载时尝试自动跳转到最后一分钟。

需要注意：

- 此功能默认关闭。
- 开启开关时，不会立即跳转已经打开的当前视频。
- 对每个识别到的视频只尝试一次，避免反复跳转。
- 自动跳转进度不等于完成视频任务点。

如需操作当前视频，请使用「跳到最后 1 分钟」按钮。

5. 自动播放与章节切换

启用脚本后，程序会尝试识别页面中的视频播放器。

视频正常播放结束时，会尝试切换到课程目录中的下一学习小节。

遇到无视频内容、页面结构异常或无法识别的学习步骤时，脚本可能停止自动操作，避免持续错误跳转。

涉及章节测验、作业或其他需要参与的任务时，请手动查看和完成。

6. 调整悬浮面板

- 移动位置：按住面板顶部标题区域进行拖动。
- 调整大小：拖动面板右下角。
- 收起面板：点击右上角「收起」。
- 展开面板：点击「展开」。

面板布局会保存在浏览器本地，刷新后通常可以恢复之前的布局。

⚙️ 设置保存说明

脚本会通过浏览器本地存储记录部分设置，包括：

设置项目| 默认状态
脚本总开关| 开启
播放倍速| 1.5×
后续自动跳转| 关闭
面板位置与尺寸| 初始布局
面板收起状态| 展开

这些设置保存在当前浏览器对应站点的本地存储中。

更换浏览器、使用不同网站域名或清除站点数据后，设置可能无法保留。

❓ 常见问题

Q1：安装后为什么没有出现悬浮面板？

请依次检查：

1. Tampermonkey 是否成功安装并启用。
2. 用户脚本是否处于启用状态。
3. 是否已打开具体课程的学习页面，而不是课程列表或首页。
4. 是否已刷新课程页面。
5. 浏览器扩展权限是否允许脚本在当前网站运行。

脚本需要等待课程页面加载。若页面目录始终无法识别，可能出现启动超时提示。

Q2：脚本出现了，但视频没有自动播放？

可能原因包括：

- 视频播放器尚未加载完成。
- 浏览器限制自动播放。
- 课程页面结构发生变化。
- 视频嵌入页面存在访问限制。
- 当前课程不是脚本支持的视频学习页面。

可以先手动打开视频，确认能够正常播放，再刷新页面尝试。

Q3：为什么设置了倍速却没有变化？

部分课程播放器会主动恢复播放倍速，或禁止使用高于正常速度的倍速。

脚本会有限次数地尝试应用设置，但无法保证所有课程都能成功。

请查看面板中的「实际倍速」，不要只依据「设置倍速」判断是否生效。

Q4：为什么点击跳转后，进度没有变化？

部分课程限制拖动视频进度。

如果播放器拒绝跳转，脚本会显示相应提醒。

建议正常播放视频并根据课程要求完成学习。

Q5：为什么视频结束后没有自动进入下一节？

可能是课程目录结构变化、下一节不是视频、存在需要手动完成的任务，或页面切换失败。

请检查课程目录，必要时手动选择下一小节。

Q6：视频已经播放完，学习进度为什么没有完成？

视频播放结束不等于平台已经记录任务完成。

学习通的任务点、观看时长与课程完成状态由平台进行判断。某些课程可能设置额外的学习条件。

请以学习通页面显示的官方学习记录为准。

Q7：为什么关闭脚本后，刷新页面仍然没有运行？

面板总开关的状态会被保存。

如果之前手动关闭了脚本，重新打开课程时可能仍然保持关闭状态。

打开悬浮面板，重新开启「启用脚本」即可。

🔄 更新脚本

建议定期查看仓库以了解新版本。

更新方法：

1. 进入本项目 GitHub 仓库。
2. 打开最新的 "v3_optimized.user.js" 文件。
3. 复制最新脚本代码。
4. 打开 Tampermonkey 中已安装脚本的编辑页面。
5. 替换旧代码并保存。
6. 刷新学习通课程页面。

也可以尝试重新打开脚本安装链接，按照油猴提示更新。

当前脚本没有单独配置自动更新地址，因此不保证能够自动检测 GitHub 上的新提交。

🗑️ 卸载方法

如果不再需要使用：

1. 打开 Tampermonkey 管理面板。
2. 找到「学习通自动刷课脚本 V3 稳定版」。
3. 选择禁用或删除。
4. 刷新学习通页面。

禁用脚本后，刷新页面即可不再加载对应功能。
